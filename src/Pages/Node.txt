1. What is Node.js?
Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser. 
It is mainly used to build backend applications, APIs, and server-side logic.

2.What can Node.js do?
✅ Connect with MongoDB
✅ Read and manage files
✅ Create APIs
✅ Authenticate users
✅ Generate JWT tokens
✅ Upload images
✅ Send emails

3.Is Node.js a programming language?
4.No. It is a runtime environment.

5.Is Node.js a framework?
No. Node.js is a runtime environment. Express.js is a framework built on top of Node.js.

6.Why can't React connect directly to MongoDB?
React should not connect directly to MongoDB because database credentials would be exposed to users. 
Instead, React sends requests to the backend (Node.js), and the backend securely communicates with the database.

7.What is Express.js?
Express.js is a lightweight web framework built on top of Node.js
It simplify backend development by providing features like routing(GET,POST,PUT,DELETE),
Middleware(JWT,Authentication,Logging) and Req,Res handling

18.What is Middleware?
Middleware is a function that executes between the request and the response. It can inspect, modify,
validate, or stop the request before it reaches the controller.

Request => Middleware=>Controller=>Response

19.What can Middleware do?
Middleware can:
✅ Check JWT
✅ Authentication
✅ Authorization
✅ Logging
✅ Validation
✅ Error Handling

20.What is next()?
next() is a function used to pass control from the current middleware to the next middleware
or route handler.
Middleware=>next()=>controller

21.What happens if we don't call next()?
If we don't call next(), the request stops in the current middleware. 
The controller will not execute, and the client may not receive a response.

22.Authentication Middleware
Authentication Middleware verifies the user's identity by checking whether a valid JWT token is present. 
If the token is valid, it calls next() and allows the request to continue. Otherwise, it returns 401 Unauthorized.

23.Authorization Middleware
Authorization Middleware checks whether the authenticated user has permission to access a specific resource or
perform a specific action based on their role (such as Admin or Employee). If the user does not have permission, it returns 403 Forbidden.

24.401 Unauthorized
The user is not authenticated.
401 Unauthorized means the user is not authenticated. This usually happens when the JWT token is missing, invalid, or expired.

25.403 Forbidden
The user is authenticated, but does not have permission.
403 Forbidden means the user is authenticated, but does not have permission to perform the requested action.

What is WHERE?
The WHERE clause is used to filter records based on a specified condition.

SELECT * FROM employees
WHERE id=2;

SELECT * FROM employees
WHERE role="Admin";

UPDATE employees
SET role="Manager"
WHERE id=2;

DELETE FROM employees
WHERE id=2;

Why do we use the WHERE clause?
We use the WHERE clause to retrieve, update, or delete 
only the records that match a specific condition.

What is the difference?
SELECT * FROM employees;
VS
SELECT * FROM employees
WHERE id = 2;

SELECT * FROM employees; retrieves all employee details.
SELECT * FROM employees WHERE id = 2; retrieves only employee ID 2.

What happens if we run DELETE FROM employees;
Without the WHERE clause it will delete all employee data.

1.What is LIMIT?
LIMIT is used to restrict the number of rows returned by a SQL query.

SELECT * FROM employees
LIMIT 10;

2.Why do we use LIMIT?
We use LIMIT to improve performance, reduce the amount of data returned, and implement pagination.

What happens if we don't use LIMIT for a table with 1,00,000 records?
Without LIMIT, the database may return thousands of records, making the API slower, increasing memory usage, and causing the UI to load slowly.


Which feature in React commonly uses LIMIT?
Pagination

What is OFFSET?
OFFSET is used to skip a specified number of rows before returning records. 
It is commonly used with LIMIT to implement pagination.

LIMIT             vs           OFFSET
How many rows                 How many rows to skip
LIMIT 10                      OFFSET 20

Why do we use OFFSET?
We use OFFSET to skip a specified number of rows and retrieve the next set of records. 
It is commonly used with LIMIT to implement pagination.
SELECT * FROM employees
LIMIT 10 OFFSET 0;

What is the difference between LIMIT and OFFSET?
Specifies how many rows to return.
Example: LIMIT 10

Specifies how many rows to skip.
Example: OFFSET 20

Write SQL for: Page 4 Page size = 10?
OFFSET = (Page Number - 1) × Page Size
OFFSET = (4 - 1) × 10 = 30

SELECT * FROM employees
ORDER BY employee_id
LIMIT 10 OFFSET 30;

1.What is JOIN?
JOIN is used to combine data from two or more tables based on a related column.

SELECT employees.name,
departments.department
FROM employees
JOIN departments
ON employees.department_id=departments.id

2.Why do we use JOIN?
We use JOIN to retrieve related data from multiple tables in a single query.

3.Can we get the Department Name from the Employee table alone? Why?
No. We cannot get the department name from the Employee table alone because it only stores the Department ID.
We need to JOIN the Departments table to retrieve the department name.

4.Which column is used to connect the two tables?
id(employees.department_id and departments.id) column is used to connect the two tables using JOIN.

1.What is Prisma ORM?
Prisma ORM is an Object Relational Mapping tool that allows Node.js applications to interact with databases 
using JavaScript instead of writing raw SQL queries.

await prisma.employee.findMany(); With Prisma
------------------------------------------------
Another Example
Without Prisma;
INSERT INTO employees(name,email)

With Prisma
await prisma.employee.create({

    name: "Kalai",
    email: "kalai@gmail.com"
  }
});
