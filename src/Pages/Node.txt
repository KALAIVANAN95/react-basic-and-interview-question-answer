1. What is Node.js?
Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser.
Node.js is not a programming language. It is a JavaScript runtime environment.

2.What can Node.js do?
✅ Connect with MongoDB
✅ Read and manage files
✅ Create APIs
✅ Authenticate users
✅ Generate JWT tokens
✅ Upload images
✅ Send emails
