Q1. React Architecture
Explain the component architecture of a large-scale React application that you have built. How did you manage state, routing, and reusability?
Answer:
In a large React application, I organize the project by features or modules, such as authentication, dashboard, projects, and users. Each module contains its own components, 
pages, services, and Redux files. I use reusable common components such as buttons, tables, modals, and form fields. 
I manage global state using Redux Toolkit and local UI state using useState. For routing, I use React Router with protected routes based on authentication and user roles.

Q2. Redux State Management
Describe a complex Redux implementation you have worked on. When would you prefer Context API over Redux?
Answer:
I used Redux Toolkit to manage global data such as user details, authentication, projects, and API data.
I used slices, reducers, and async thunks for API calls and loading or error states.
 I use Context API for simple global data, such as theme or language. I prefer Redux when the application has complex shared state and many components need the same data.

Q3. TypeScript
How does TypeScript improve maintainability in large products? Explain interfaces, types, generics, and utility types with examples.
Answer:
TypeScript is a superset of JavaScript that adds static typing.
It improves maintainability by catching type errors during development and making code easier to understand. I
use interfaces and types to define the structure of objects, such as user data and API responses. Generics help create reusable functions or components that work with different data types. 
Utility types like Partial, Pick, and Omit help reuse and modify existing types without repeating code.

Q4. Node.js Event Loop
Explain the Node.js event loop and how asynchronous programming works internally.
Answer:
The event loop is a mechanism in Node.js that continuously checks the call stack and callback queue. 
When the call stack is empty, it moves pending callbacks to the call stack for execution.

Event is a mechanism in JavaScript that handles asynchronous operations by continuously checking the call stack and callback queue, and moving tasks to the stack when it becomes empty.

Q6. REST vs GraphQL
Compare REST APIs and GraphQL. In which scenarios would you recommend each approach?
Answer:
REST uses multiple endpoints for different resources, such as /users or /projects. 
GraphQL uses a single endpoint and allows the frontend to request only the fields it needs. 
I would use REST for simple APIs and GraphQL when the frontend needs flexible data from multiple resources.
