### 3. Difference between null and undefined?

i) Null - Intentional null (empty) value of variable.
ii) Undefined - Declared variable without any value.

Example:
let a;
console.log(a); // undefined

let b = null;
console.log(b); // null

### 4. How to declare variable in JS?

Can declare variable using

i) var = function scoped
ii) let = block scoped
iii) const = block scoped - cannot be reassigned

Example:
var a = 10;
let b = 20;
const c = 30;

console.log(a, b, c);

### 5. What is Closure in JS?

A closure allows inner functions to access outer function variables even after execution.

Example:
function outer() {
let count = 0;

return function inner() {
count++;
console.log(count);
};
}

const counter = outer();

counter(); // 1
counter(); // 2

---

### 6. Difference between == and ===?

i) == (loose equality): compares values after type coercion.
ii) === (strict equality): compares both value and type.

== checks value only.
=== checks both value and datatype.

I prefer === to avoid unexpected type coercion.

Example:
console.log(5 == "5");   // true
console.log(5 === "5");  // false

### 9. What is Promise in JS?

Promises are used to handle asynchronous operations with success and failure states.

It has methods like .then() and .catch().

It will be in one of the 3 possible states

i) Fulfilled
ii) Rejected
iii) Pending

Example:
const promise = new Promise((resolve, reject) => {
resolve("Success");
});

promise
.then(result => console.log(result))
.catch(error => console.log(error));

### 11. Currying?

Currying is a technique of evaluation function with multiple arguments into sequence of function with single argument.

Example:

```javascript
function add(a) {
  return function(b) {
    return a + b;
  };
}

console.log(add(2)(3)); // 5
```

### 12. What is this keyword?

This keyword is a reference variable that refers to the current object.

Example:

```javascript
const user = {
  name: "Kala",
  showName() {
    console.log(this.name);
  }
};

user.showName(); // Kala
```

### 13. Diff btwn forEach and map method?

The map() method returns a new array, whereas the forEach() method does not return a new array.

or

map() is used to iterate arrays and return a new transformed array.

Example:

```javascript
const numbers = [1, 2, 3];

// map
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6]

// forEach
numbers.forEach(num => console.log(num));
```

### 14. apply bind call

call() – invokes the function immediately, arguments passed one by one.

apply() – invokes the function immediately, arguments passed as an array.

bind() – does not invoke immediately, returns a new function with this fixed, and you can pass arguments.

Example:

```javascript
const person = {
  name: "Kala"
};

function greet(city) {
  console.log(this.name + " " + city);
}

greet.call(person, "Chennai");
greet.apply(person, ["Chennai"]);

const fn = greet.bind(person, "Chennai");
fn();
```

### 15. async and await

"async and await make promises easier to write."

async makes a function return a Promise.

await pauses execution until the Promise resolves (or rejects).

Example:

```javascript
async function getData() {
  const data = await Promise.resolve("Hello");
  console.log(data);
}

getData();
```

### 17. Map

### 18. Filter

filter() returns array elements that satisfy a condition.

Example:

```javascript
const numbers = [1, 2, 3, 4, 5];

const even = numbers.filter(num => num % 2 === 0);

console.log(even); // [2, 4]
```

---

### 19. Reduce?

reduce() is used to reduce an array to a single value (like sum, total, or object) by applying a function.

Example:

```javascript
const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((total, num) => total + num, 0);

console.log(sum); // 10
```

### 20. setTimeout vs setInterval

Both are used to run code after a delay, but behavior is different.

**setTimeout**
Runs once after a given delay.

Example:

```javascript
setTimeout(() => {
  console.log("Hello");
}, 2000);
```

**setInterval**
Runs repeatedly at every interval.

Example:

```javascript
setInterval(() => {
  console.log("Hello");
}, 2000);
```
