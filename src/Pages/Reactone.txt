### 3.What is the meaning of Virtual DOM.?
Virtual DOM is a lightweight copy of the Real DOM.
When state or props change, React creates a new Virtual DOM, compares it with the previous Virtual DOM, and updates only the changed parts in the Real DOM.
This improves performance and makes React applications faster.

**Example:**
```jsx

<button onClick={() => setCount(count + 1)}>
  Increment
</button>
```

### 8.What are the three phases of a component life cycle in React.?
The React component lifecycle consists of three main phases:

1. Mounting
* The component is created and inserted into the DOM.

2. Updating
* The component is re-rendered when props or state change.
3. Unmounting
* The component is removed from the DOM.

**Example:**

### 13.What are refs in React?

Refs are used to access DOM elements directly and store mutable values without causing component re-renders.
Main uses:

ii)To join third party DOM libraries
iii)To manage focus and apply media playback

### 22.What is the difference between Real DOM and Virtual DOM?
Real DOM:
The real DOM updates slower.
The real DOM can directly update HTML.
Every update may cause re-rendering of DOM elements.

Virtual DOM:
The virtual DOM updates faster.
The virtual DOM cannot directly update HTML.
React compares the old and new Virtual DOM using a diffing algorithm.
Only the changed elements are updated in the Real DOM.

**Example:**
```jsx
const [count, setCount] = useState(0);

<button onClick={() => setCount(count + 1)}>
  {count}
</button>
```

### 30.Hooks?
Hooks are special functions in React that allow functional components to use React features.
In functional components, Hooks are used to:
i) manage state
ii) handle lifecycle-like behavior
iii) access the DOM

Hooks can also manage stateful logic and side effects.

**Example:**

```jsx
import { useState, useEffect } from "react";

function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log("Component Loaded");
  }, []);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

### 33.Why dependency array important?
Dependency array controls when the effect should execute.
[] -> runs once
[value] -> runs when value changes
No dependency -> runs on every render
**Example:**
```jsx
// Runs only once
useEffect(() => {
  console.log("Mounted");
}, []);

// Runs when count changes
useEffect(() => {
  console.log(count);
}, [count]);
```

### 38.What is lifting state up?
Lifting state up means moving shared state to the nearest common parent.
OR
When multiple child components need shared data, state is moved to the common parent component and passed using props.
Example Scenario
Search input component
Search results component
Both need the same search text, so the state is maintained in the parent component and shared via props.
**Example:**

```jsx
const [search, setSearch] = useState("");

<SearchInput value={search} onChange={setSearch} />
<SearchResult search={search} />
```
