### 3.What is the meaning of Virtual DOM.?
Virtual DOM is a lightweight copy of the Real DOM.
When state or props change, React creates a new Virtual DOM, compares it with the previous Virtual DOM, and updates only the changed parts in the Real DOM.
This improves performance and makes React applications faster.

**Example:**
```jsx
const [count, setCount] = useState(0);
<button onClick={() => setCount(count + 1)}>
  Increment
</button>
```

### 8.What are the three phases of a component life cycle in React.?
The React component lifecycle consists of three main phases:

1. Mounting
* The component is created and inserted into the DOM.

2. Updating
* The component is re-rendered when props or state change.
3. Unmounting
* The component is removed from the DOM.

**Example:**

```jsx
useEffect(() => {
  console.log("Mounted");

  return () => {
    console.log("Unmounted");
  };
}, []);
```

### 13.What are refs in React?
Refs are a function provided by React to access the DOM element and the React element that you might have created on your own.

Refs are used to access DOM elements directly and store mutable values without causing component re-renders.
Main uses:
i)To initiate imperative animations
ii)To join third party DOM libraries
iii)To manage focus and apply media playback

**Example:**
```jsx
const inputRef = useRef();
<input ref={inputRef} />
<button onClick={() => inputRef.current.focus()}>
  Focus
</button>
```

### 14.What are the components of Redux in React?
Redux consists of 4 main components as shown below:
i)Action: An object that describes the call
ii)Reducer:The state change storage unit
iii)Store:The state and object tree storage
iv)View:Displays data provided by the store
Redux consists of Actions, Reducers, Store, and Dispatch, which work together to manage application state.

**Example:**
```javascript

```

### 22.What is the difference between Real DOM and Virtual DOM?

Real DOM:

The real DOM updates slower.

The real DOM can directly update HTML.

Every update may cause re-rendering of DOM elements.

Virtual DOM:

The virtual DOM updates faster.

The virtual DOM cannot directly update HTML.

React compares the old and new Virtual DOM using a diffing algorithm.

Only the changed elements are updated in the Real DOM.

**Example:**

```jsx
const [count, setCount] = useState(0);

<button onClick={() => setCount(count + 1)}>
  {count}
</button>
```

---

### 23.Controlled vs uncontrolled components?

Controlled components are managed using React state.

Uncontrolled components use refs.

In most enterprise applications I use controlled components because validation and form handling become easier.

**Example:**

```jsx
// Controlled
const [name, setName] = useState("");

<input
  value={name}
  onChange={(e) => setName(e.target.value)}
/>

// Uncontrolled
const inputRef = useRef();

<input ref={inputRef} />
```

### 29.Differentiate between stateless and stateful components.

Stateless:

It is simple and easy to understand.

It is also known as a functional component.

Stateful:

It is complex as compared to the stateless component.

It is also known as a class component.

**Example:**

```jsx
// Stateless
function Header() {
  return <h1>Header</h1>;
}

// Stateful
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

### 30.Hooks?

Hooks are special functions in React that allow functional components to use React features.

In functional components, Hooks are used to:

i) manage state

ii) handle lifecycle-like behavior

iii) access the DOM

Hooks can also manage stateful logic and side effects.

**Example:**

```jsx
import { useState, useEffect } from "react";

function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log("Component Loaded");
  }, []);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```
