### 3.What is the meaning of Virtual DOM.?
Virtual DOM is a lightweight copy of the Real DOM.
When state or props change, React creates a new Virtual DOM, compares it with the previous Virtual DOM, and updates only the changed parts in the Real DOM.
This improves performance and makes React applications faster.

**Example:**

### 22.What is the difference between Real DOM and Virtual DOM?
Real DOM:
The real DOM updates slower.
The real DOM can directly update HTML.
Every update may cause re-rendering of DOM elements.

Virtual DOM:
The virtual DOM updates faster.
The virtual DOM cannot directly update HTML.
React compares the old and new Virtual DOM using a diffing algorithm.
Only the changed elements are updated in the Real DOM.

**Example:**
```jsx
const [count, setCount] = useState(0);

<button onClick={() => setCount(count + 1)}>
  {count}
</button>
```

### 33.Why dependency array important?
Dependency array controls when the effect should execute.
[] -> runs once
[value] -> runs when value changes
No dependency -> runs on every render
**Example:**
```jsx

  console.log("Mounted");
}, []);

// Runs when count changes
useEffect(() => {
  console.log(count);
}, [count]);
```

### What is useSelector?
useSelector is used to read data from the Redux store.
**Example:**

```javascript
const users = useSelector(
  (state) => state.user.users
);
```
---

### What is dispatch?
dispatch is used to send actions for fetching or updating data.
**Example:**

```javascript
dispatch(getUsers());
```

---

### What is Reducer?
Reducer is a function that updates the store based on the action received.
**Example:**
```javascript
const counterSlice = createSlice({
  name: "counter",
  initialState: 0,
  reducers: {
    increment: (state) => state + 1,
  },
});
```
---

### createSlice
createSlice creates and manages a specific part of the Redux store.

**Example:**
```javascript
const userSlice = createSlice({
  name: "user",
  initialState: {},
  reducers: {},
});
```

---

### Why use Redux?
Redux provides centralized state management and helps avoid prop drilling in large applications.
**Example:**

```text
Multiple Components
        ↓
   Redux Store
        ↓
Shared Data
```

### Less Common / Advanced Hooks
**useLayoutEffect** → runs before browser paint (DOM measurement)
**Example:**

```jsx
useLayoutEffect(() => {
  console.log("Before Paint");
}, []);
```

**useImperativeHandle** → customize ref behavior
**Example:**

```jsx
useImperativeHandle(ref, () => ({
  focus: () => inputRef.current.focus(),
}));
```

**useId** → generate unique IDs (React 18+)
**Example:**
```jsx
const id = useId();

<label htmlFor={id}>Name</label>
<input id={id} />
```
**useTransition** → handle UI transitions smoothly
**Example:**
```jsx
const [isPending, startTransition] = useTransition();
```
**useDeferredValue** → defer updating non-urgent UI updates

**Example:**
```jsx
const deferredSearch = useDeferredValue(search);
```
